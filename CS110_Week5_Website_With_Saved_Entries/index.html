PART 01

Explain Week 1–4

Four quick stops that tell a newcomer what you learned and how the pieces connect.

01
🧭

Mindset + support

Learning web development is iterative: try, inspect, revise, and ask for help. A mistake is useful information when you can explain what you tried and what happened.

TRY→TEST→REVISE
02
🎭

Story + genre + hats

A story gives the project a purpose. Genre sets expectations for the kind of experience. The Visual, Logical, and Data hats are different ways to inspect the same project: appearance, behavior, and information.

VISUALLOGICALDATA
03
🧩

Web tools + reusable code

HTML structures content, CSS styles it, and JavaScript adds behavior. VS Code is the workspace; Git/GitHub tracks and shares versions. A reusable npm package is like a shelf item: your project can use code someone already packaged instead of rebuilding that capability from scratch.

HTMLCSSJS+📦 PACKAGE
04
🌐

Browser + name server + server

The browser requests a website. A name system such as DNS helps translate a domain name into an address. The server sends back the requested files or data, and the browser turns them into the page you see.

Browser→DNS→Server→Page
